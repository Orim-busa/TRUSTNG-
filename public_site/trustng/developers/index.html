Developer Information

Prototype

API-first approach

TrustNG is being developed around an API that allows systems to submit information for risk assessment and receive structured advisory responses.

Prototype

Authentication

Protected endpoints use API-key authentication. API credentials must be kept private and must never be embedded in public browser code or shared repositories.

Advisory

Assessment outcomes

Responses may include risk assessments and policy recommendations. These outputs are informational and do not execute or authorise financial transactions.

Sandbox-oriented

Testing environment

Sandbox workflows are intended for controlled development and testing. Simulated results must not be interpreted as real payment settlement or production verification.

Not yet production-ready

Integration readiness

Production partner documentation, stable integration contracts, service-level commitments and provider-specific implementation guides will require further development and validation.
